# The Practical AI Developer Stack

One small stack per profile. **Learn many → evaluate → choose few → master
them.** Last verified: September 2026.

| Profile | Stack | Rationale |
| --- | --- | --- |
| **Beginner** | VS Code + Copilot Free + (later) Cline | Autocomplete/chat first; add an agent only once you review diffs confidently |
| **Student** | Copilot Free + Cline (capped BYOK) + Ollama small + Gemini CLI | $0, every niche, maximum transferable learning — see the [student guide](../workflows/student.md) |
| **Solo developer** | Cline or Cursor + Claude Code or Aider | One IDE agent + one terminal agent; add MCP servers for your stack |
| **Startup** | Copilot Business + Claude Code + Qodo PR-Agent + Mintlify | Standardize, automate review, ship docs — see [best-for-startups](../../comparisons/best-for-startups.md) |
| **Professional engineer** | Editor agent (Copilot/Cursor) + terminal agent (Claude Code/Aider) + rules files + MCP to real services | Coverage without overlap; review discipline assumed |
| **Open-source developer** | Aider (git-native) + Qodo PR-Agent + Cline + Jules for issue triage | Free/BYOK, GitHub-centric, community-friendly |
| **Local AI enthusiast** | Ollama + Continue + Aider + Tabby | Fully offline capability — sized honestly to your RAM |
| **Enterprise developer** | Copilot Enterprise / Q Developer Pro / Gemini Code Assist / Tabnine — whichever your org contracts | Contractual privacy + audit; personal tools stay home |

## Standing principles

1. One tool per niche — overlap is waste ([tool overlap](../../comparisons/tool-overlap.md)).
2. Autonomy is a dial; increase it only as verification matures.
3. Never blindly accept AI code ([rules](../guides/ai-coding-rules.md)).
4. Fundamentals first: DSA, Git, databases, testing, architecture, security.
   AI accelerates the learning — it does not replace it.
