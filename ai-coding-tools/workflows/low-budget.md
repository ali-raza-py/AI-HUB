# Low-Budget Workflow

See [pricing analysis](../docs/comparisons/pricing.md) and the
[student guide](../docs/workflows/student.md).

**$0:** Copilot Free + Cline + free-tier API key (Gemini/OpenRouter free
models) + Ollama small models.
**~$5/mo:** add a capped BYOK key; spend it only on hard problems.
**Rules:** cap spend, prefer hybrid (local for cheap tasks, cloud for hard),
never run unsupervised agent loops on paid keys, and re-verify free-tier
limits monthly — they move.
