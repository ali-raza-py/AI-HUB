# Open-Source Workflow

- **Aider** for git-native pair programming (commits are its native unit).
- **Cline/Kilo Code** for multi-file features in VS Code.
- **Qodo PR-Agent** (open source) for automated PR review on your repo.
- **Jules / OpenHands** to turn issues into draft PRs — with branch
  protection and human review, always.
- Keep an `AGENTS.md`/rules file so contributors' agents follow project
  conventions.
- License note: don't point agents at GPL-incompatible code if your license
  must stay permissive — check what gets embedded.
