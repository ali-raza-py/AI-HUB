# Startup Workflow

See [best tools for startups](../comparisons/best-for-startups.md).

Rollout: one editor standard (Copilot Business or Cursor) + one terminal
agent for seniors (Claude Code) + PR review automation (Qodo) + hosted docs
(Mintlify). Enforce branch protection, CI-green-before-merge, scoped tokens.
Measure cycle time and defect rate — not "AI usage".
