# Beginner Workflow

1. Install **VS Code** + **GitHub Copilot Free**.
2. Use autocomplete + chat for two weeks. Read every suggestion before
   accepting.
3. Learn the vocabulary: [beginner concepts](../docs/getting-started/beginners.md),
   [concepts & definitions](../docs/getting-started/concepts.md).
4. Add **Cline** with a free-tier API key; run one small task with permission
   prompts on; read every diff.
5. Read [AI coding rules](../docs/guides/ai-coding-rules.md) before expanding
   anything.

Stop here until steps 2–4 are habit.
