# Best Tools for Students

> Last verified: September 2026. Also read the full
> [student guide](../docs/workflows/student.md) and
> [pricing analysis](../docs/comparisons/pricing.md).

| Tool | Cost for students | Why | Watch out |
| --- | --- | --- | --- |
| **GitHub Copilot** | Free tier (Pro free via GitHub Student Pack — verify eligibility) | Zero-friction autocomplete + chat + agent mode in VS Code; best GitHub integration | Free tiers have limits; don't let it replace learning |
| **Cline** | Free tool + your key | Best BYOK learning platform: see plans, diffs, MCP, every agent step | You pay per token; keep spend caps |
| **Kilo Code** | Free tool + your key | Cline/Roo-lineage agent, generous free credits historically — verify | Overlaps Cline — pick one |
| **Gemini CLI** | Generous free tier | Free agentic terminal work; good for learning CLI agents | Limits/behavior change often |
| **OpenCode / Aider** | Free + BYOK | Open-source terminal agents; Aider teaches git-native flow | Leaner than commercial agents |
| **Continue** | Free + BYOK/local | Open-source; one config for IDE + local models | Less polished than commercial |
| **Ollama** | Free | Learn local models hands-on | 8 GB RAM = 3B–8B models only, slow on CPU |
| **Docusaurus / Sphinx / TypeDoc / JSDoc / pdoc** | Free, open source | Documentation craft — an underrated employable skill | Not AI — you do the writing |

**Avoid for students (for now):** paid AI IDEs (Cursor/Windsurf subscriptions
before you've outgrown free stacks), enterprise platforms (Copilot
Enterprise, Q Developer Pro, watsonx), cloud autonomous agents (Devin) —
great to *understand*, unnecessary to *pay for* while learning.

**The student stack:** Copilot Free + Cline (capped BYOK key) + Ollama.
$0, covers every niche, and every hour spent in it teaches transferable
skills — agent architecture, MCP, prompt design, review discipline.
